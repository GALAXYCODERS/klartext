# Examples

Finished pages and presentations built with Klartext. Each example lives in its own folder with a short `README.md` (what it shows, a screenshot, how to open or build it).

There are no published examples yet — the decks the system grew out of contain group work and third-party material and stay private for now.

**Add yours:** copy your project into `examples/<short-name>/` (without `node_modules/`, large `dist/` files, `.env` or screenshot folders), add a README, make sure it contains no private data (names, e-mail addresses, internal information, images or logos you have no rights to), and open a pull request. If it ships its own copy of the library, note which Klartext version it uses.
